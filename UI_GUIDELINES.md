# ThaalDraft UI Guidelines

## Product Positioning

ThaalDraft is not a file formatter.

ThaalDraft is an AI-powered Manuscript Intelligence Workspace.

The interface must feel like:

- Notion
- Grammarly
- Linear
- Overleaf

Combined into a single publishing workflow.

The product should communicate:

- Trust
- Professionalism
- Precision
- Intelligence
- Simplicity

---

# Core UX Philosophy

## Rule 1

Focus on the manuscript.

Never focus on the platform.

The manuscript is the hero.

The interface is secondary.

---

## Rule 2

Reduce Cognitive Load

Every screen must answer:

1. Where am I?
2. What should I do next?
3. What requires attention?

Immediately.

---

## Rule 3

One Primary Action Per Screen

Bad:

Upload
Citation Check
Formatting
Compliance
Export

all on one screen.

Good:

One clear next step.

---

## Rule 4

Progressive Disclosure

Advanced options must remain hidden until needed.

Do not overwhelm users.

---

# Animations

Purposeful only.

Loading

Feedback

---

# Empty States

Every empty state must:

Explain the feature.

Explain why it matters.

Provide a clear next action.

---

# Error States

Never blame the user.

Always:

Explain issue.

Provide resolution.

Provide retry action.

---

"I am working inside a professional publishing workspace designed specifically for researchers."

Not:

"I am using another AI tool."

Not:

"I am using a dashboard."

Not:

"I am using a file converter."
